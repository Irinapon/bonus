# Veranda — концепт лендинга

Статичный премиальный лендинг велнес-клуба Veranda (Смоленск), по мотивам референса «Счастье на Родине».

Открыть: `index.html` (без сборки). Файлы: `index.html`, `styles.css`, `main.js`.

Перед запуском в прод:
- заменить фото Unsplash на собственные фото клуба (все `<img>` и `--img` в `index.html`);
- заменить черновые отзывы в секции `#reviews` на реальные (Яндекс Карты / 2ГИС);
- проставить ссылки соцсетей в футере.
