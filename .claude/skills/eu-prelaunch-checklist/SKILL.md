# Pre-launch checklist для сайтов, ориентированных на Европу

Уровни:
- **P0 - критично:** без этого сайт нельзя выпускать в продакшен.
- **P1 - обязательно к запуску:** качество, продажи, SEO, доверие, UX.
- **P2 - улучшения:** можно после запуска, если не создают юридических или технических рисков.

**Европа - не одна юрисдикция.** Требования ЕС, Великобритании и Швейцарии различаются; во Франции, Германии и других странах есть национальные правила. Юридические пункты - это список вопросов к юристу, а не юридическая консультация. Нормы меняются: перед запуском сверяйте даты и статус актов по официальным источникам (внизу).

## Как проводить аудит

1. **Определить тип сайта и рынки:** корпоративный / заявки / e-commerce / SaaS / платформа; страны ЕС, UK, CH; B2B или B2C. Разделы, которые не применимы, отмечать `N/A` с причиной (например, раздел 09 для сайта без оплаты).
2. **Автоматизировать всё, что можно** (Playwright / curl / скрипты): горизонтальный скролл на всех ширинах, битые ссылки и якоря, HTTP-коды, title/description/H1, hreflang/canonical, alt и размеры изображений, ошибки консоли, контраст, cookies и сторонние запросы до согласия, размеры ресурсов.
3. **Вручную:** юридические тексты против фактической обработки данных, переводы, сценарии со скринридером и клавиатурой, реальная заявка или заказ, реальные устройства.
4. **Отчёт:** по каждому пункту статус `✅ ок` / `⚠️ частично` / `❌ нет` / `N/A`, доказательство (что проверено и как) и что сделать. Сначала все P0, затем P1, затем P2. Отдельно - что требует решения клиента или юриста, а что можно исправить сразу.
5. Не отмечать пункт `✅`, если он не проверен фактически. «Не могу проверить отсюда» - это `⚠️` с пояснением.

## 01. Бизнес, домен и юридическая информация
- [ ] P0 - Определено юридическое лицо, которое управляет сайтом.
- [ ] P0 - На сайте указаны официальное название компании, юридический адрес и контакты.
- [ ] P0 - Проверены регистрационные данные компании, VAT ID (если применимо).
- [ ] P0 - Определены страны, в которых сайт предлагает товары или услуги.
- [ ] P0 - Проверены требования каждой целевой страны.
- [ ] P0 - Если компания вне ЕС/UK, но работает с людьми в ЕС/UK: назначен представитель в ЕС (GDPR ст. 27) и/или в UK (UK GDPR ст. 27), если нет исключения.
- [ ] P0 - Privacy Policy описывает фактическую обработку данных именно этого сайта (формы, сервисы, шрифты, аналитика, хостинг) и правильного владельца.
- [ ] P0 - Обязательные юридические уведомления: Impressum (Германия, DDG), mentions légales (Франция, LCEN) и аналоги.
- [ ] P0 - Terms & Conditions / Terms of Use, если применимо.
- [ ] P0 - Для e-commerce: условия продажи, оплаты, доставки, возврата и отмены.
- [ ] P0 - Соблюдение GDPR / UK GDPR / Swiss nFADP (revFADP, с 1.09.2023).
- [ ] P0 - Основания трансграничной передачи данных (EU-US Data Privacy Framework, SCC, решения об адекватности).
- [ ] P0 - Заключены DPA с обработчиками данных (хостинг, формы, CRM, email, аналитика, AI-сервисы).
- [ ] P0 - Ведётся реестр обработки (ROPA), определено, нужен ли DPO.
- [ ] P1 - Указаны права потребителей и порядок претензий. Ссылку на платформу ODR ЕС - **убрать** (платформа закрыта 20.07.2025).
- [ ] P1 - Проверены права на фото, шрифты, видео, тексты, товарные знаки, AI-сгенерированные материалы (лицензии сервисов).
- [ ] P1 - Определено, нужна ли регистрация торговой марки.
- [ ] P1 - Отраслевые уведомления, лицензии и ограничения.
- [ ] P1 - AI Act ст. 50 (с 2.08.2026): пользователь информирован, что общается с ИИ (чат-боты), маркировка синтетического контента, где требуется.
- [ ] P1 - Для платформ и маркетплейсов: требования DSA (контактные точки, notice-and-action, прозрачность, проверка продавцов).

## 02. GDPR, cookies и согласия
- [ ] P0 - Инвентаризация cookies, localStorage, пикселей, SDK, сторонних скриптов, шрифтов и встраиваний (YouTube, карты).
- [ ] P0 - Необязательные cookies и трекеры не запускаются до действительного согласия (ePrivacy; Германия - TDDDG §25; UK - PECR).
- [ ] P0 - «Принять» и «Отклонить» одинаково доступны на первом уровне, без манипулятивного интерфейса (позиция CNIL/EDPB).
- [ ] P0 - Можно выбрать отдельные категории (если необязательных категорий больше одной).
- [ ] P0 - Согласие можно изменить или отозвать в любой момент (ссылка в футере).
- [ ] P0 - Отказ действительно блокирует соответствующие скрипты (проверить сетевые запросы).
- [ ] P0 - Согласие фиксируется (дата, выбор, версия текста); срок повторного запроса - по практике регулятора (CNIL: до 13 месяцев).
- [ ] P0 - Шрифты, иконки и CDN не передают IP третьим лицам без основания: предпочтительно хранить шрифты на своём сервере (Google Fonts - решение LG München, 2022).
- [ ] P0 - В формах нет заранее отмеченных чекбоксов согласия.
- [ ] P0 - Маркетинговые согласия отделены от необходимых действий (заказ, заявка).
- [ ] P0 - Проверена передача данных в Google Analytics, Meta Pixel, CRM, чат, email-сервисы и AI-инструменты.
- [ ] P1 - Указаны сроки хранения персональных данных.
- [ ] P1 - Определён процесс запросов субъектов данных (доступ, исправление, удаление) - сроки 1 месяц.
- [ ] P1 - Формы подписки: double opt-in, где требуется или целесообразно (Германия - фактически обязателен).
- [ ] P1 - Баннер протестирован на мобильных и всех языках сайта; не перекрывает ключевые действия.

## 03. Структура, контент и локализация
- [ ] P1 - Утверждены карта сайта, навигация и структура.
- [ ] P1 - У каждой страницы понятная цель и следующий шаг.
- [ ] P1 - Все CTA ведут на правильные страницы, формы или действия.
- [ ] P1 - Нет пустых разделов, тестового текста, заглушек, ссылок `#`.
- [ ] P1 - Контакты, адреса, телефоны, часы работы проверены.
- [ ] P1 - Переводы вычитаны носителем языка.
- [ ] P1 - Правильные валюты, единицы, даты, форматы чисел.
- [ ] P1 - Проверены названия услуг и коммерческие термины для рынка.
- [ ] P1 - Юридические документы на необходимых языках (Франция - Loi Toubon: потребительский контент на французском).
- [ ] P1 - Переключатель языков работает на всех страницах.
- [ ] P1 - При переключении языка пользователь остаётся на эквивалентной странице.
- [ ] P1 - Нет переполнения текста в кнопках, меню, карточках, формах (особенно немецкий, французский, японский).
- [ ] P2 - Локальные отзывы, кейсы, социальные доказательства.

## 04. Дизайн, адаптивность и UX
- [ ] P0 - Нет горизонтального скролла и перекрытий на основных разрешениях.
- [ ] P0 - Меню, формы, модальные окна и ключевые действия работают на мобильных.
- [ ] P1 - Мобильные ширины 320, 360, 375, 390, 430 px.
- [ ] P1 - Планшеты, ноутбуки, большие мониторы.
- [ ] P1 - Safari, Chrome, Firefox, Edge.
- [ ] P1 - Реальные iPhone и Android, если доступны.
- [ ] P1 - Кликабельные области не меньше 24×24 px (WCAG 2.5.8), лучше 44×44.
- [ ] P1 - Шрифты читаемы, длина строки разумная.
- [ ] P1 - Контраст текста достаточен (4.5:1 обычный текст, 3:1 крупный и элементы интерфейса).
- [ ] P1 - Оформлены состояния hover, focus, active, disabled, error.
- [ ] P1 - Недоступные кнопки не выглядят активными.
- [ ] P1 - Анимации не мешают чтению и навигации.
- [ ] P1 - Учтён `prefers-reduced-motion`.
- [ ] P1 - Изображения корректно кадрируются.
- [ ] P1 - Проверены страницы 404, успешной отправки формы и ошибки.
- [ ] P2 - Проверена понятность основных сценариев.

## 05. Accessibility / European Accessibility Act
EAA применяется с 28.06.2025 к определённым продуктам и услугам (в т.ч. e-commerce для потребителей, банковские услуги, электронные коммуникации, транспорт, e-books). Микропредприятия, оказывающие услуги (до 10 сотрудников и до 2 млн € оборота или баланса), освобождены. Гармонизированный стандарт EN 301 549 ссылается на WCAG 2.1 AA; проверять лучше по WCAG 2.2 AA.
- [ ] P0 - Определено, подпадает ли сайт под EAA и есть ли исключения.
- [ ] P0 - Основные сценарии доступны с клавиатуры.
- [ ] P0 - Формы, оплата, аутентификация доступны со вспомогательными технологиями.
- [ ] P1 - У функциональных изображений есть текстовые альтернативы.
- [ ] P1 - Декоративные изображения скрыты от скринридера (`alt=""`, `aria-hidden`).
- [ ] P1 - Видимый фокус клавиатуры.
- [ ] P1 - Нет ловушек клавиатуры.
- [ ] P1 - У полей программно связанные labels.
- [ ] P1 - Ошибки форм объясняются текстом, а не только цветом.
- [ ] P1 - Иерархия заголовков логична.
- [ ] P1 - Указан язык страницы и языковые фрагменты (`lang`).
- [ ] P1 - Читается при масштабе 200% и reflow на 320 px.
- [ ] P1 - Модальные окна, меню, аккордеоны, динамические сообщения (`aria-live`).
- [ ] P1 - Автоматически движущийся контент дольше 5 секунд (видео, анимации, карусели) можно поставить на паузу (WCAG 2.2.2).
- [ ] P1 - У видео с речью есть субтитры и альтернативы.
- [ ] P1 - Контраст, ссылки, интерактивные элементы.
- [ ] P1 - Ручной тест со скринридером (VoiceOver, NVDA).
- [ ] P1 - Заявление о доступности / информация по EAA, если требуется.

## 06. SEO и индексация
- [ ] P0 - На продакшене нет случайного `noindex` / `nofollow`.
- [ ] P0 - robots.txt не блокирует важные страницы.
- [ ] P0 - Создан и проверен sitemap.xml.
- [ ] P0 - Выбран основной домен, настроены редиректы (www ↔ без www, http → https).
- [ ] P1 - Уникальный Title у каждой индексируемой страницы.
- [ ] P1 - Корректный meta description у важных страниц.
- [ ] P1 - Один H1 и последовательная структура заголовков.
- [ ] P1 - canonical URL.
- [ ] P1 - Взаимные hreflang, включая `x-default`.
- [ ] P1 - Коды hreflang по ISO 639-1 (+ ISO 3166-1 для региона): `ja`, а не `jp`; `en-GB`, а не `en-UK`.
- [ ] P1 - Нет битых внутренних ссылок и якорей.
- [ ] P1 - 301-редиректы со старых URL (на статическом хостинге - meta refresh/JS + canonical как временная мера).
- [ ] P1 - Страницы ошибок отдают правильные HTTP-коды (404, а не 200).
- [ ] P1 - JSON-LD (Organization, WebSite, Product, FAQ…), если применимо.
- [ ] P1 - Open Graph и превью соцсетей (1200×630).
- [ ] P1 - favicon, apple-touch-icon, manifest.
- [ ] P1 - Google Search Console и Bing Webmaster Tools.
- [ ] P1 - Отправлен sitemap.
- [ ] P2 - Стратегия контента и локального SEO.

## 07. Производительность
- [ ] P1 - Изображения оптимизированы, WebP/AVIF.
- [ ] P1 - У изображений заданы размеры (`width`/`height` или `aspect-ratio`) против CLS.
- [ ] P1 - Отложенная загрузка ниже первого экрана.
- [ ] P1 - Изображение первого экрана без задержки (`fetchpriority="high"`, без `loading="lazy"`).
- [ ] P1 - Шрифты оптимизированы, лишние начертания удалены, `font-display: swap`.
- [ ] P1 - Нет лишних JS и CSS.
- [ ] P1 - Сторонние скрипты не блокируют загрузку.
- [ ] P1 - Видео сжато, есть poster, не грузится на мобильных без необходимости.
- [ ] P1 - Кэширование статических ресурсов (версионирование имён/параметров).
- [ ] P1 - Core Web Vitals: LCP ≤ 2.5 с, INP ≤ 200 мс, CLS ≤ 0.1.
- [ ] P1 - PageSpeed Insights / Lighthouse, мобильная и десктопная версии.
- [ ] P2 - Работа на медленном мобильном интернете.

## 08. Формы, заявки, CRM и коммуникации
- [ ] P0 - Каждая форма отправляет данные правильному получателю.
- [ ] P0 - Заявки не теряются при ошибке уведомления (резервный канал или хранилище, понятная ошибка с контактом).
- [ ] P0 - Заявки доходят в CRM, если интегрирована.
- [ ] P0 - Нет тестовых API-ключей на продакшене; секретные ключи не в публичном коде (публичные ключи форм-сервисов - допустимо, если ограничены доменом).
- [ ] P1 - Валидация обязательных полей.
- [ ] P1 - Проверка email, телефона, размеров файлов.
- [ ] P1 - Ошибки отправки показываются пользователю.
- [ ] P1 - Подтверждение успешной отправки.
- [ ] P1 - Автоответы и уведомления менеджерам.
- [ ] P1 - SPF, DKIM, DMARC отправляющего домена.
- [ ] P1 - Защита от спама (honeypot, rate limit, капча с учётом GDPR).
- [ ] P1 - Ссылки mailto:, tel:, WhatsApp и другие каналы.
- [ ] P1 - Поведение формы без сети и при повторной отправке (блокировка кнопки).
- [ ] P1 - Согласия и источник заявки передаются в CRM.
- [ ] P1 - Рядом с формой - ссылка на Privacy Policy (информирование по GDPR ст. 13).

## 09. Интернет-магазин, оплата и доставка
Для e-commerce и платных сервисов (включая SaaS-подписки B2C).
- [ ] P0 - Корректные названия, характеристики, цены и варианты товаров.
- [ ] P0 - Цена для потребителя включает налоги и обязательные сборы.
- [ ] P0 - Дополнительные расходы раскрыты до подтверждения заказа.
- [ ] P0 - Оплата проходит в тестовом и реальном сценарии.
- [ ] P0 - 3D Secure / SCA (PSD2), если применимо.
- [ ] P0 - Поведение после успешной, отклонённой и прерванной оплаты.
- [ ] P0 - Повторное нажатие не создаёт дубль заказа.
- [ ] P0 - Возвраты денег и отмена платежей.
- [ ] P0 - 14-дневное право отказа в ЕС и UK, исключения, образец формы отказа.
- [ ] P0 - Функция отказа от договора («withdraw from contract here») для договоров онлайн - Директива (EU) 2023/2673, с 19.06.2026.
- [ ] P0 - Для подписок: Германия - кнопка расторжения (§312k BGB), Франция - résiliation en 3 clics.
- [ ] P0 - Информация о законной гарантии соответствия (в ЕС минимум 2 года).
- [ ] P0 - Кнопка финального заказа однозначно сообщает об обязанности оплатить («Order with obligation to pay» / «zahlungspflichtig bestellen»).
- [ ] P0 - При скидках показана самая низкая цена за 30 дней до скидки (Директива Omnibus).
- [ ] P1 - Корректный расчёт доставки, налогов, скидок, промокодов.
- [ ] P1 - Страны доставки и ограничения.
- [ ] P1 - Складские остатки, нельзя купить недоступный товар.
- [ ] P1 - Подтверждение заказа на долговечном носителе (email).
- [ ] P1 - Заказы доходят менеджеру и в CRM.
- [ ] P1 - Счета, инвойсы, VAT, OSS/IOSS.
- [ ] P1 - Физические товары: GPSR (с 13.12.2024), маркировка, безопасность.
- [ ] P1 - Франция: CGV, право отказа, обязательная информация, требования к e-commerce.

## 10. Безопасность и инфраструктура
- [ ] P0 - HTTPS на всех страницах.
- [ ] P0 - Сертификат действителен и обновляется автоматически.
- [ ] P0 - HTTP перенаправляет на HTTPS.
- [ ] P0 - DNS, основной домен, редирект www.
- [ ] P0 - Нет секретов, токенов и приватных ключей в публичном коде и истории git.
- [ ] P0 - Тестовые аккаунты, пароли, админ-маршруты защищены или удалены.
- [ ] P0 - Резервные копии и проверенное восстановление.
- [ ] P0 - Процедура отката на предыдущую версию.
- [ ] P1 - Security headers, CSP (на статическом хостинге без заголовков - CSP через `<meta>` и прокси/CDN при необходимости).
- [ ] P1 - Обновлены зависимости, плагины, CMS.
- [ ] P1 - Минимально необходимые права доступа.
- [ ] P1 - MFA для административных аккаунтов (хостинг, регистратор домена, git, формы).
- [ ] P1 - Защита от перебора и злоупотребления API.
- [ ] P1 - CORS, загрузка файлов, защита ввода.
- [ ] P1 - Ошибки не раскрывают секреты и пути.
- [ ] P1 - Мониторинг доступности, ошибок, срока домена и сертификата; автопродление домена.
- [ ] P1 - Ответственные за хостинг, домен, поддержку, восстановление.

## 11. Аналитика и маркетинг
- [ ] P0 - Аналитика соответствует модели согласий.
- [ ] P1 - GA4, Matomo или другой инструмент (Matomo/Plausible без cookies могут не требовать согласия - проверить по стране).
- [ ] P1 - Google Consent Mode v2 для Google-тегов в ЕЭЗ/UK (обязателен для Google Ads с 03.2024).
- [ ] P1 - События: отправка формы, клик по телефону, заявка, покупка.
- [ ] P1 - Конверсии не дублируются.
- [ ] P1 - UTM-метки и сохранение источника.
- [ ] P1 - Исключён внутренний и тестовый трафик.
- [ ] P1 - Google Ads, Meta Pixel и другие интеграции.
- [ ] P1 - Отчётность по странам, языкам, устройствам.
